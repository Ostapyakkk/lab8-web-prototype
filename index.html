Про проєкт

Ця веб-сторінка розроблена як базовий прототип для демонстрації структури HTML5-документа та розгортання статичного сайту за допомогою сервісу GitHub Pages.

Використані технології

  • HTML5 — розмітка структури сторінки;
  • CSS3 — базове оформлення блоків, шрифтів та відступів;
  • Git та GitHub — контроль версій та хостинг проєкту.

Етапи виконання роботи

  1. Створення локального файлу index.html.
  2. Написання базової розмітки та додавання контенту.
  3. Створення публічного репозиторію на GitHub.
  4. Завантаження файлів та активація GitHub Pages.

Детальніше про документацію HTML можна прочитати на MDN Web Docs.
